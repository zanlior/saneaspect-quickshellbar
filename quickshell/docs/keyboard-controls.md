# Keyboard controls

The expanded media and power panels take keyboard focus when they open, including
when the bar uses Dock, Workspace, Notch, or Game Mode layouts.

## Media

- **Left / Right** moves to the previous or next player. The carousel wraps at
either end and settles on the selected player.
- **Space** toggles play/pause for the player shown on the card. Each physical
key press sends one command. Space does nothing when there is no player, while
a swipe is active, or while the carousel is settling.
- Playback and seeking controls continue to target the displayed player.

Opening the panel selects the most recently started or resumed player. Moving
between layouts while the panel is open keeps keyboard focus on the media card.

## Power menu

The menu opens with **Lock** highlighted. Use **Left / Up** to move to the
previous action and **Right / Down** to move to the next; navigation wraps
through Lock, Suspend, Log Out, Reboot, and Power Off.

Press **Enter** or **Return** to activate the highlighted action. Lock runs
immediately. Other actions display **Confirm?** on the first press and run only
after a second distinct press. Moving the highlight cancels confirmation. A
held key does not count as a second press. **Escape** closes the menu without
running an action. Clicking an action selects and activates it through the same
confirmation behavior.
